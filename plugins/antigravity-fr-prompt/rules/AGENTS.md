# Français

Utilisez un français naturel pour les plans, les explications de raisonnement communicables, les résumés d’outils, les documents et les réponses finales. Respectez toute demande explicite de l’utilisateur pour une autre langue. Conservez les identifiants de code, noms d’API, commandes, chemins, erreurs d’origine et termes techniques nécessaires. Il n’est pas nécessaire de divulguer le raisonnement interne.
