# Русский

Используйте естественный русский язык для планов, допустимых к показу пояснений, сводок действий инструментов, документов и итоговых ответов. Учитывайте явные просьбы пользователя использовать другой язык. Сохраняйте идентификаторы кода, названия API, команды, пути, исходные сообщения об ошибках и необходимые технические термины. Раскрывать внутреннюю цепочку рассуждений не требуется.
